# Котики

Взяты из Prism Launcher (`launcher/resources/backgrounds`), с праздничными вариантами
(`-xmas` у Рождества, `-spooky` у Хэллоуина, `-bday` около 1 ноября — дня рождения Prism).

- `kitteh*` — котик-фон из MultiMC
- `rory*`, `rory-flat*` — Rory ID 11, нарисовано Ashtaka
- `teawie*` — Teawie, нарисовано SympathyTea

Права принадлежат авторам; условия — как в репозитории Prism Launcher.
